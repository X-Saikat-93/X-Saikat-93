## 08 — Operating Principles

<table>
<tr>
<td width="25%" valign="top">

### 01

**Product before code**

The best technical decision starts with understanding the user, the business goal, and the workflow.

</td>
<td width="25%" valign="top">

### 02

**Clarity over cleverness**

Readable systems scale better than over-engineered ones. Simple code wins when the product grows.

</td>
<td width="25%" valign="top">

### 03

**Design is engineering**

Great UI is not decoration. It is structure, hierarchy, feedback, accessibility, and speed.

</td>
<td width="25%" valign="top">

### 04

**Ship, learn, refine**

Build the useful version first, measure what matters, then improve with intent.

</td>
</tr>
</table>
